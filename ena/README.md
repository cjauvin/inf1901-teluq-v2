# Coquille ENA d'INF 1901 (v2)

Coquille : <https://ena.teluq.ca/course/view.php?id=402>, sur le modèle de celle d'INF 1410
(<https://ena.teluq.ca/course/view.php?id=206>).

- `bandeau-inf1901.jpg` : l'image du cours (paramètres du cours, « Image de cours »), recadrée
  dans `static/images/hal_and_clippy_v2.png` (bande y = 560 à 1240). L'ENA l'affiche recadrée
  au centre, en bande d'environ 4,5 pour 1.
- Section « Bienvenue ! » : texte, bouton vers le site, signature (HTML dans le résumé de section).
- Section « Évaluations » : cinq aiguilleurs d'activités (notés sur 15, 20, 20, 20 et 25),
  chacun avec un « Segment 1 » qui pointe vers son devoir.
- Section « Pages cachées » (cachée) : les cinq devoirs, disponibles mais invisibles sur la page,
  remise d'un fichier PDF, une tentative, consigne qui renvoie à la page du travail sur le site.
