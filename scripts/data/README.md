# Données

- `titanic3.csv` : la liste complète des passagers du *Titanic* (1309 lignes), compilée par
  Thomas Cason (Université de Virginie) à partir de l'*Encyclopedia Titanica*, telle que
  distribuée par le dépôt de données de Frank Harrell (Université Vanderbilt) :
  <https://hbiostat.org/data/repo/titanic.html>. Domaine public. Sert à
  `scripts/gen_arbre_titanic.py`.
- `epoch-calcul.csv` : le calcul d'entraînement estimé des modèles notables sortis depuis 2018
  (392 modèles), avec leur statut de modèle de frontière et l'ouverture de leurs poids, extrait
  en novembre 2026 de la base d'Epoch AI : <https://epoch.ai/data/notable_ai_models.csv>.
  Licence CC BY 4.0. Sert à `scripts/gen_frontiere_calcul.py`.
